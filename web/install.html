Use desktop Chrome or Edge for USB flashing. You can still download firmware and use esptool. USB flashing requires HTTPS or localhost. Download firmware for command-line installation.

Close other serial monitors and editor tabs first. Choose your knob in the USB port picker. The installation dialog shows flash progress and any errors.

Saved data and backups

A normal update preserves this project's saved views and motor calibration. Leave Erase device unchecked to preserve them. Selecting it erases the whole flash, including views, calibration, and factory data.

Factory firmware uses a different format; its settings cannot be imported. Before replacing it, make a full-flash backup. The browser installer cannot make this backup. Export editor projects as JSON separately.

Back up and restore with esptool

Install Python and pip install esptool==5.5.0. Close all USB connections and replace PORT with your serial port.

esptool --chip esp32s3 --port PORT read-flash 0x0 0x1000000 smartknob-backup.bin

Keep the 16 MB backup somewhere safe. To restore it:

esptool --chip esp32s3 --port PORT write-flash 0x0 smartknob-backup.bin

First installation and recovery

  1. Use a USB data cable and connect the knob. Close any serial monitor.
  2. If the knob is missing or connection fails, use the buttons on its back: hold BOOT, press and release EN/RST, then release BOOT. Select the USB port again if it changes.
  3. Click Connect & install. Choose whether to erase and confirm the version in the dialog. Keep USB connected until installation finishes.
  4. If USB disconnects or flashing fails, close the dialog, repeat the BOOT/EN-RST sequence, and retry. A failed write can be recovered through the ROM bootloader.
  5. After success, close the dialog and press EN/RST if the knob stays in boot mode. Return to the editor and click Connect USB. Complete hardware bring-up and calibration before enabling motor feedback.

The button sequence is documented by Seedlabs; recovery with this firmware remains untested on hardware.

Install a downloaded firmware image

Use the image and checksums from the same build. In an extracted release archive, verify and flash:

sha256sum -c SHA256SUMS
esptool --chip esp32s3 --port PORT write-flash 0x0 firmware.bin

This is one Zephyr simple-boot image at offset zero. No separate bootloader or partition table is required.
